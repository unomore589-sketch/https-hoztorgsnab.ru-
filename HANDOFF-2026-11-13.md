## 3. Как устроены корзина и раздел каталога (разведка, чтобы не копать заново)

**Корзина** (`/cart.html`, ресурс «Корзина» id 12, псевдоним `cart`, шаблон «Корзина»). Содержимое ресурса:
- `[[!mSearchForm? &element=`msProducts` &tplForm=`tpl.mSearch2.Cart.form` ...]]` — строка быстрого добавления товара «ДОБАВИТЬ В ЗАКАЗ»;
- `[[!msBasketsList? &tpl=`tpl.msBaskets.form`]]` — сохранённые корзины;
- `[[!msCart? &tpl=`tpl.msCart`]]` — сама корзина.

Чанк `tpl.msCart` (папка `miniShop2`) написан на **Fenom** (`{foreach}`, `{if}`); miniShop2 парсит его своим шаблонизатором. Поэтому:
- CSS и JS внутри него обязаны лежать между `{ignore}` и `{/ignore}`, иначе Fenom принимает фигурные скобки за свои теги и корзина не рисуется (владелец проверял 21.09.2026);
- после изменения количества miniShop2 перерисовывает корзину с сервера **без обработки тегов MODX** (`[[...]]`), поэтому в перерисованной части они остаются сырыми. Розничная цена строки для проверки минимума поэтому берётся через Fenom (`data-retail`), а не через тег MODX;
- в чанке уже есть логика минимального заказа 3 000 ₽ (настройка `hts_min_order`, плагин `hts_min_order_guard`, сниппет `htsRetail`), её не трогали.

«Копия tpl.msCart» (147) — старая версия на других классах (`hts-cart`). В ней есть расчёт цены через сниппет `kss_get_prices_and_discount` (оптовая цена от количества: `opt_count`, `opt_price`). В рабочем `tpl.msCart` цена строки — просто `{$product.price}`.

**Раздел каталога**: шаблон «Подкатегория» (id 18). Товары и фильтры выводит `[[!mFilter2? ...]]` (59 фильтров по TV-полям в списке `&filters`, из них на странице видны только те, у кого есть значения в разделе; `&ajaxMode=scroll`, `&limit=24`, свой порядок сортировки: сначала в наличии, потом по цене). Разметка страницы собирается из чанков `[[$sidebarcategory]]` и `[[$contentcategory]]` внутри `<div class="row msearch2" id="mse2_mfilter">`. Карточку товара в списке рисует чанк `kss_msProducts` — **его код ещё не получали**.

## 4. Причины и что именно сделано

**Корневые причины** (все в общем файле стилей шаблона, сборка minifyx `styles_*.min.css`; имя файла меняется при пересборке, исходник не смотрели):
- `@media (max-width:480px) .stepper { display:none !important }` прятала поле количества в корзине вместе со стрелками;
- `.js #msCart [type="submit"][value="cart/change"] { display:none }` прячет кнопку «обновить»: miniShop2 шлёт изменение по событию `change` поля;
- `@media (max-width:480px) .sidebar_right { display:none }` прятала всю боковую колонку, а фильтры mSearch2 лежат в ней.

**Решение для корзины.** Вместо плагина `stepper` свои кнопки «−» и «+» (42 × 42 px) и поле на 16 px. Нажатие меняет число в поле и вызывает `jQuery(input).trigger('change')`; дальше всё делает miniShop2. Быстрые нажатия сводятся в один запрос (пауза 400 мс), ниже 1 не опускается. Обработчик висит на `document`, поэтому работает и после перерисовки корзины.

**Решение для фильтров.** Над списком кнопка «Фильтры» (со счётчиком выбранных). По нажатию та же колонка `.sidebar_right` показывается панелью снизу экрана: заголовок, фильтры, «Сбросить», «Показать N товаров» (N берётся из события `mse2_load`). Затемнение вставляется рядом с колонкой, а не в `body`: у `#wrapper1` свой слой (`z-index:1`), и затемнение из `body` ложилось поверх панели. Сами фильтры и их работа не менялись. На экранах шире 480 px блок ничего не делает.

## 11. Дополнение: блок «Добавить товар по-быстрому» в корзине

Пользователь заметил «1490 1490». Это не задвоение: в блоке (`#cart_prod`, чанк `tpl.mSearch2.Cart.form`, сценарий

плюс общее `.stepper`). Вторая ошибка: `.cost` считается только в момент выбора товара и не меняется вместе с количеством
(и на компьютере). В корзину при этом уходит правильное количество.

- Чанк `HtsCartQuickAdd` (`modx-chunks/hts-cart-quick-add.html`), вызов `[[$HtsCartQuickAdd]]` в содержимом ресурса 12
  **перед** `<div class="ms2_total_products">` (содержимое этого div miniShop2 перерисовывает после каждого изменения).
- До 800px: до выбора — только поиск; после — название целиком, «N ₽ за шт.», «−»/«+», «Сумма», кнопка во всю ширину;
  после добавления — «✓ Добавлено…» и очистка блока. Шире 800px раскладка прежняя, только `.cost` пересчитывается.
- Стрелки плагина `stepper` сообщают об изменении через `jQuery.trigger('change')`, обычного события нет — слушать через jQuery.
- Пакет `audit/sql/quick-add/`, тест `audit/sql/test_package_quick_add.py`, проверка подстановкой `audit/scripts/verify-quick-add.js`.
