# Личный кабинет hoztorgsnab.ru — мобильная версия

Правки для сайта hoztorgsnab.ru (MODX Revolution 2.7.0-pl).

## Задача

В личном кабинете (`/profil.html`, ресурс 81) вкладка «История заказов» выводится
виджетом ExtJS из пакета **Office** (`[[!officeMiniShop2?]]` → сниппет `Office`,
`action = miniShop2`). ExtJS рассчитывает ширину колонок в пикселях под десктоп,
поэтому на телефоне таблица нечитаема — колонки обрезаются до 1–2 символов.

## Решение

Не переписываем ExtJS-виджет (unsupported с 2012-х, ломкий), а добавляем рядом
собственный мобильный список, который берёт данные из того же API пакета Office:

| Что | Запрос |
|-----|--------|
| Список заказов | `POST /assets/components/office/action.php` — `action=minishop2/getOrders&start=0&limit=20&pageId=81` |
| Состав заказа | `POST /assets/components/office/action.php` — `action=minishop2/getOrderProducts&start=0&limit=50&order_id=<ID>&pageId=81` |

Переключение видом через CSS media query:

- ширина > 768px — показывается штатный ExtJS-грид, мобильный блок скрыт (десктоп не затронут);
- ширина ≤ 768px — грид `#office-minishop2-grid` скрыт, показываются карточки заказов.

## Файлы

| Файл | Куда вставлять в MODX |
|------|------------------------|
| `modx-chunks/lichny-kabinet-mobile.html` | Элементы → Чанки → чанк `LichnyKabinetMobile` (id 207), поле «Код чанка (HTML)» |
| `modx-templates/profil.html` | Шаблон «Профиль» (Личный кабинет 81 → Настройки → Шаблон → Открыть), поле «Код шаблона (HTML)» |

В шаблоне относительно исходного добавлен только вызов `[[$LichnyKabinetMobile]]`
внутри `<div ... id="zakaz">`, сразу после `[[!officeMiniShop2?]]`.

## Не сделано

Кнопка «Повторить заказ» (добавление всех товаров заказа в корзину одним нажатием).
Сервер такого действия не отдаёт — у заказа в `actions` есть только `viewOrder`.
Чтобы её добавить, нужно снять реальный запрос добавления товара в корзину
(DevTools → Network при ручном добавлении товара) и вызвать тот же метод miniShop2
для каждой позиции заказа.
