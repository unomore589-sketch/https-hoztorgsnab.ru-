степпер и свайп-галерея в товаре, восстановление прокрутки после «Назад», CLS ≤ 0,04,
gzip + HTTP/2, статика кэшируется на 45 дней.

## План

1. **Убрать препятствия** — находки 1–3, 5, 7, 8, 10–13.
2. **Мобильная навигация** — нижняя панель (каталог, поиск, корзина, кабинет, звонок) и
   шапка в одну строку; поиск на весь экран с фото и ценой; вид «списком» с − / +;
   закреплённая кнопка «В корзину» и шкала до 3 000 / 35 000 ₽; «Повторить заказ».
3. **Технологии** — Speculation Rules, WebP + lazy-loading, PWA, голосовой поиск,
   заказ по списку артикулов, подбор по описанию задачи.

Первый шаг: количество в корзине и кнопка «Фильтры». Нужны шаблон корзины и шаблон раздела каталога.

## Повторный замер

```
node audit/scripts/audit.js <папка для скриншотов>   # цифры по 7 страницам → metrics.json
node audit/scripts/flow.js  <папка для скриншотов>   # сценарий покупки → flow.json
```

Скрипты ждут Playwright в `/opt/node-tools/node_modules/playwright` и Chromium в
`/opt/pw-browsers/chromium`; `flow.js` кладёт один товар в корзину гостевой сессии.
